# Student Performance Analyzer

A beginner-friendly Python project that analyzes student marks and generates a result report.

## Features
- Accepts student name and subject-wise marks
- Validates marks between 0 and 100
- Calculates total marks and percentage
- Assigns a grade and pass/fail status
- Identifies highest and lowest scoring subjects
- Displays subject-wise performance analysis

## Python Concepts Used
- Variables and data types
- Conditional statements
- Loops
- Functions and return values
- Dictionaries
- Exception handling
- Built-in functions such as `sum()`, `max()` and `min()`

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Run:

```bash
python student_analyzer.py
```
